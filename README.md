## Claude Code setup

`.claude/skills/` carries a vendored copy of [obra/superpowers](https://github.com/obra/superpowers)
(MIT, Jesse Vincent) — fourteen skills covering TDD, systematic debugging, planning,
code review and subagent workflows. They load automatically in any Claude Code session on
this repository, local or cloud, with nothing to install. Start with `using-superpowers`.

See `.claude/skills/SUPERPOWERS.md` for provenance, what was changed from upstream, and
how to re-sync.
